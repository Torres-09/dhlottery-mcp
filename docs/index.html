🔒 입력한 정보는 서버로 전송되지 않으며, 설정 파일 생성에만 사용됩니다.

STEP 3 바이너리 다운로드 & 설정 파일 생성
⬇ 바이너리 다운로드
  1. 압축 해제
    다운로드한 dhlottery-mcp_darwin_arm64.tar.gz 를 더블클릭하거나 아래 명령어로 해제하세요.
    tar xzf dhlottery-mcp_darwin_arm64.tar.gz
  2. 바이너리 이동
    mkdir -p ~/.local/bin
mv dhlottery-mcp ~/.local/bin/
  3. PATH 확인 (필요한 경우)
    ~/.local/bin이 PATH에 없다면 셸 설정 파일에 추가하세요.
    echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc
  4. 설정 파일 다운로드 (STEP 3 버튼)
    위 "설정 파일 생성 및 다운로드" 버튼을 클릭하면 claude_desktop_config.json이 다운로드됩니다.
  5. 설정 파일을 Claude 설정 폴더에 복사
    기존 파일이 없다면 아래 명령어를 실행하세요.
    mkdir -p ~/Library/Application\ Support/Claude
cp ~/Downloads/claude_desktop_config.json ~/Library/Application\ Support/Claude/
  6. 경로 교체
    claude_desktop_config.json 안의 YOUR_HOME_PATH 부분을 실제 홈 경로로 바꾸세요.
    sed -i '' "s|YOUR_HOME_PATH|$HOME|g" ~/Library/Application\ Support/Claude/claude_desktop_config.json
  7. Claude Desktop 완전 종료 후 재시작
    메뉴바에서 완전히 종료(Cmd+Q)한 뒤 다시 실행하세요.
  1. 압축 해제
    tar xzf dhlottery-mcp_darwin_amd64.tar.gz
  2. 바이너리 이동
    mkdir -p ~/.local/bin
mv dhlottery-mcp ~/.local/bin/
  3. PATH 확인 (필요한 경우)
    echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc
  4. 설정 파일 다운로드 후 Claude 설정 폴더에 복사
    mkdir -p ~/Library/Application\ Support/Claude
cp ~/Downloads/claude_desktop_config.json ~/Library/Application\ Support/Claude/
  5. 경로 교체
    sed -i '' "s|YOUR_HOME_PATH|$HOME|g" ~/Library/Application\ Support/Claude/claude_desktop_config.json
  6. Claude Desktop 완전 종료 후 재시작
  1. 압축 해제
    tar xzf dhlottery-mcp_linux_amd64.tar.gz
  2. 바이너리 이동
    mkdir -p ~/.local/bin
mv dhlottery-mcp ~/.local/bin/
  3. PATH 확인 (필요한 경우)
    echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc && source ~/.bashrc
  4. 설정 파일 다운로드 후 Claude 설정 폴더에 복사
    mkdir -p ~/.config/Claude
cp ~/Downloads/claude_desktop_config.json ~/.config/Claude/
  5. 경로 교체
    sed -i "s|YOUR_HOME_PATH|$HOME|g" ~/.config/Claude/claude_desktop_config.json
  6. Claude Desktop 완전 종료 후 재시작
  1. 압축 해제
    다운로드한 dhlottery-mcp_windows_amd64.zip을 우클릭 → "모두 압축 풀기"
  2. 바이너리 이동
    압축을 푼 dhlottery-mcp.exe를 원하는 위치로 이동합니다.
    %LOCALAPPDATA%\Programs\dhlottery-mcp\
  3. 설정 파일 위치 확인
    아래 경로의 폴더가 없다면 만들어 주세요.
    %APPDATA%\Claude\
  4. 설정 파일 복사 및 경로 편집
    다운로드한 claude_desktop_config.json을 %APPDATA%\Claude\에 복사한 뒤, 텍스트 편집기로 열어 YOUR_HOME_PATH를 실제 경로로 교체하세요.
    C:\Users\사용자명\AppData\Local\Programs\dhlottery-mcp\dhlottery-mcp.exe
  5. Claude Desktop 완전 종료 후 재시작
    트레이 아이콘 우클릭 → 종료 후 다시 실행하세요.

🔒 보안 안내
