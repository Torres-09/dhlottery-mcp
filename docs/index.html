Claude에서 자연어로 로또를 구매하고 당첨번호를 확인하세요

버전 확인 중… ⭐ GitHub
STEP 1 운영체제 선택
STEP 2 계정 정보 입력 (선택 사항)

🔒 입력한 정보는 서버로 전송되지 않으며, 설정 파일 생성에만 사용됩니다.
입력하지 않아도 당첨번호 조회 등은 바로 사용할 수 있습니다.

STEP 3 바이너리 다운로드 & 설정 파일 생성
⬇ 바이너리 다운로드
  1. 바이너리 다운로드 후 압축 해제
    위 "바이너리 다운로드" 버튼 클릭 → 다운로드된 .tar.gz 파일 더블클릭으로 압축 해제
    같은 폴더에 dhlottery-mcp 파일이 생깁니다.
  2. 실행 권한 부여 (터미널에서 1회만)
    Spotlight(⌘+Space)에서 "터미널" 검색 후 열고, 아래 명령어를 붙여넣고 Enter:
    chmod +x ~/Downloads/dhlottery-mcp
  3. 설정 파일 다운로드
    위 "설정 파일 생성 및 다운로드" 버튼 클릭 → claude_desktop_config.json 다운로드
  4. 설정 파일을 Claude 설정 폴더에 복사
    Finder에서 ⌘+Shift+G를 누르고 아래 경로를 붙여넣은 뒤 이동:
    ~/Library/Application Support/Claude
    폴더가 없으면 새로 만드세요. 다운로드한 설정 파일을 이 폴더에 복사합니다.
  5. Claude Desktop 완전 종료 후 재시작
    메뉴 막대에서 Claude 아이콘 우클릭 → Quit Claude 또는 ⌘+Q 후 재시작
⚠️ 보안 경고가 뜨는 경우 시스템 환경설정 → 개인 정보 보호 및 보안 → "확인 없이 허용" 클릭
  1. 바이너리 다운로드 후 압축 해제
    위 "바이너리 다운로드" 버튼 클릭 → 다운로드된 .tar.gz 파일 더블클릭으로 압축 해제
  2. 실행 권한 부여 (터미널에서 1회만)
    Spotlight(⌘+Space)에서 "터미널" 검색 후 열고 아래 명령어 실행:
    chmod +x ~/Downloads/dhlottery-mcp
  3. 설정 파일 다운로드
    위 "설정 파일 생성 및 다운로드" 버튼 클릭
  4. 설정 파일을 Claude 설정 폴더에 복사
    Finder에서 ⌘+Shift+G 후 아래 경로 붙여넣기:
    ~/Library/Application Support/Claude
    다운로드한 설정 파일을 이 폴더에 복사합니다.
  5. Claude Desktop 완전 종료 후 재시작
⚠️ 보안 경고가 뜨는 경우 시스템 환경설정 → 개인 정보 보호 및 보안 → "확인 없이 허용" 클릭
  1. 바이너리 다운로드 후 압축 해제
    위 "바이너리 다운로드" 버튼 클릭 → 파일 관리자에서 .tar.gz 우클릭 → "여기에 압축 풀기"
  2. 실행 권한 부여
    터미널에서 아래 명령어 실행:
    chmod +x ~/Downloads/dhlottery-mcp
  3. 설정 파일 다운로드
    위 "설정 파일 생성 및 다운로드" 버튼 클릭
  4. 설정 파일을 Claude 설정 폴더에 복사
    파일 관리자에서 ~/.config/Claude/ 폴더로 이동 후 설정 파일 복사
    (폴더가 없으면 새로 만드세요)
  5. Claude Desktop 완전 종료 후 재시작
  1. 바이너리 다운로드 후 압축 해제
    위 "바이너리 다운로드" 버튼 클릭 → 다운로드된 .zip 파일 우클릭 → "모두 압축 풀기"
    압축 해제 폴더에 dhlottery-mcp.exe가 생깁니다.
  2. 설정 파일 다운로드
    위 "설정 파일 생성 및 다운로드" 버튼 클릭
  3. 설정 파일의 경로 수정
    다운로드한 claude_desktop_config.json을 메모장으로 열어
    사용자명 부분을 본인의 Windows 사용자 이름으로 바꾸세요.
    (예: C:\Users\홍길동\Downloads\dhlottery-mcp.exe)
  4. 설정 파일을 Claude 설정 폴더에 복사
    Win+R을 누르고 아래를 붙여넣은 뒤 확인:
    %APPDATA%\Claude
    폴더가 없으면 새로 만드세요. 수정한 설정 파일을 이 폴더에 복사합니다.
  5. Claude Desktop 완전 종료 후 재시작
    트레이 아이콘 우클릭 → 종료 후 재시작
⚠️ 기존 claude_desktop_config.json이 있다면? 다운로드한 파일로 덮어쓰면 기존 MCP 서버 설정이 사라집니다. 기존 파일의 "mcpServers" 안에 아래 항목만 추가하세요.

🔒 보안 안내

입력한 계정 정보(아이디/비밀번호)는 서버로 전송되지 않습니다.

설정 파일 생성은 브라우저 내에서만 처리됩니다.


⚠️ 법적 고지

이 도구는 동행복권의 공식 API를 사용하지 않으며, 비공식 HTTP 요청 기반으로 동작합니다.

사용에 따른 모든 책임은 사용자에게 있습니다.
